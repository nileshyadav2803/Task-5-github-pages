## 🚀 Implementation

### 1. Create the Website

Created an `index.html` file for the website.

CSS customization was added using `style.css`.

### 2. Initialize Git Repository

```bash
git init
```

### 3. Add Project Files

```bash
git add .
```

### 4. Create Git Commit

```bash
git commit -m "Initial GitHub Pages Portfolio"
```

### 5. Create GitHub Repository

Created a new GitHub repository named:

```text
Task-5-github-pages
```

### 6. Connect Local Repository to GitHub

```bash
git remote add origin <repository-url>
```

### 7. Push Project to GitHub

```bash
git push -u origin main
```

---

## 🌍 GitHub Pages Deployment

GitHub Pages was enabled from:

```text
Repository
   ↓
Settings
   ↓
Pages
   ↓
Deploy from a branch
   ↓
main
   ↓
/ (root)
```

After configuration, GitHub Pages generated the live website URL.
