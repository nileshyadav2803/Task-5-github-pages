## 🚀 Implementation Workflow

### 1. Create the Website

Created the `index.html` file containing the static website.

CSS customization was added using `style.css`.

### 2. Initialize Git

The project was initialized as a Git repository.

### 3. Create the Initial Commit

The website files were staged and committed to Git.

### 4. Create a GitHub Repository

Created a new GitHub repository:

**Task-5-github-pages**

### 5. Push the Project to GitHub

The local Git repository was connected to GitHub and the project was pushed to the `main` branch.

### 6. Enable GitHub Pages

GitHub Pages was enabled from:

**Repository → Settings → Pages**

### 7. Configure Deployment

The GitHub Pages deployment was configured with:

| Setting | Value                |
| ------- | -------------------- |
| Source  | Deploy from a branch |
| Branch  | `main`               |
| Folder  | `/ (root)`           |

### 8. Access the Published Website

After deployment, the website became available through the GitHub Pages URL provided by GitHub.

---

## 🌐 GitHub Pages Configuration

The deployment follows this configuration:

**Settings → Pages → Deploy from a branch → main → / (root)**

GitHub Pages then publishes the static website from the selected branch and root directory.

## 🧠 Key Concepts

### GitHub Pages

GitHub Pages is used to host static website content directly from a GitHub repository.

### Static Website

A static website consists of files such as HTML and CSS that are served directly to visitors without requiring server-side application processing.
